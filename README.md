## Entry

🐜

The ant: a tiny, relentless grinder. It enters bounty after bounty, checks
its rank eight times a day, carries loads many times its own size, and never
stops — small, tireless, always working, humble. Not the obvious robot pick.

## Run

```sh
node main.ts
```

Writes the single emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
